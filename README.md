# Anderson Leoni — Profile Linktree

Página pessoal criada para reunir, em um único lugar, as principais informações de apresentação e contato de Anderson Leoni. O projeto funciona como um cartão de visitas digital simples, com uma estrutura leve em HTML e estilos organizados em CSS.

## ✨ Sobre o projeto

A página apresenta uma introdução pessoal, foto de perfil, atuação profissional e informações de contato. A ideia é facilitar o acesso aos dados principais sem depender de uma página complexa ou de frameworks.

## 🧰 Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo da página.
- **CSS3** — estilos visuais separados por responsabilidade.
- **Normalize.css** — consistência de estilos entre navegadores.
- **Google Fonts (Open Sans)** — tipografia da interface.
- **SVG** — ícones utilizados na apresentação das informações.

## 🚀 Como executar localmente

Não é necessário instalar dependências ou configurar um servidor para visualizar a versão atual.

1. Faça o clone do repositório:

   ```bash
   git clone https://github.com/AndersonLeoni/anderson-leoni-profile-linktree.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd anderson-leoni-profile-linktree
   ```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar a página durante o desenvolvimento.

## 🛠️ Personalização

- Edite o conteúdo e os dados apresentados em `index.html`.
- Ajuste estilos gerais em `assets/css/global.css`.
- Altere a apresentação da seção principal em `assets/css/header.css`.
- Substitua a imagem em `assets/img/profile.jpg`, mantendo o nome do arquivo, ou atualize o caminho no HTML.
- Personalize os ícones SVG em `assets/icons/`.

## 🎯 Objetivo

Este repositório também serve como projeto de estudo e prática de desenvolvimento front-end, reforçando fundamentos de HTML semântico, organização de arquivos e estilização com CSS.
